# DESIGN.md — MSEB 自定义调节 · 图文攻略 PPT

## 1. 画布与母版（A/B/C 三区）
- 画布 1280×720，安全区 padding：左右 64px、上下 40px（封面/结束页可全幅）。
- A 标题块 0–96px：页主标题 30–36px bold，左侧 accent 短竖条。
- B 内容区 96–664px：正文/卡片/表格/图。
- C 页脚条 664–720px：左「MSEB 攻略」水印 + 右「NN / 10」页码，14px 灰字。
- 内容页母版严格一致；封面/结束页自定义版式。

## 2. 颜色系统（≤4 hex）
| 角色 | hex | 用途 |
|---|---|---|
| 背景主色 | `#0B1120` | 页面底色（深空蓝） |
| 面板色 | `#13203A` | 卡片/表格底色 |
| 强调色 accent1 | `#3B82F6` | 蓝——主强调、图标、标题竖条 |
| 强调色 accent2 | `#22D3EE` | 青——渐变收尾、关键高亮 |

渐变：`linear-gradient(135deg, #3B82F6 0%, #22D3EE 100%)`（标题字/大色块/页脚条）。
半透明：卡片 `rgba(255,255,255,0.04)` 描边 `rgba(255,255,255,0.08)`；装饰光斑 `opacity 0.12`。
文字：主 `#E5EDF7`、次 `#8DA2BC`。
色彩面积：主色(背景)≈60% / 辅色(面板)≈30% / 强调≤10%（Hero 页可到 15–20%）。

## 3. 字体系统
- 标题/数字：`'Inter', 'PingFang SC', 'Microsoft YaHei', sans-serif`，bold。
- 正文：`'Inter', 'PingFang SC', 'Microsoft YaHei', sans-serif`，regular。
- 字号阶梯：封面主标 64 / 章节大字 56 / 巨型锚点 72–96 / 页主标 32 / 卡片小标 22 / 正文 18–20 / 脚注 14。
- 全篇仅用上面 1 套字体家族，标题加粗区分层级。

## 4. 信息密度
- 内容页留白 ≤ 35%；卡片填充率 ≥ 85%（尾部元素 `marginTop:auto` 钉底）。
- 每页 ≥ 1 个视觉锚点（≥44px 元素或 ≥40% B 区图/大色块）。

## 5. 配图方案（无生图）
全程使用**抽象几何 + 渐变 + 大数字**作为视觉锚点（符合 design-principle §5 允许项：背景网格、抽象几何、巨型数字、L3 角标）。不调用 ImageGen；不出现具象摄影/人物。
- L1 主视觉：封面/结束页的渐变光斑 + 巨型「13」；核心页的大号概念字。
- L3 角标：页脚「MSEB」字标 + 页码，全篇位置一致。
